# 健康报：全程化管理及教育 实现儿童哮喘长期控制

> 更新时间：2026-09-16 (UTC+8)

覃敏为哮喘患儿看诊

支气管哮喘是儿童最常见的慢性呼吸系统疾病之一。近年来，我国儿童哮喘的患病率呈总体上升趋势。20多年来，广西妇幼保健院儿童呼吸内科医护人员在儿童哮喘的诊疗、教育、病情监测和推动患者自我管理等方面做了大量工作。为进一步改善医疗服务，推动呼吸哮喘专科门诊的专业化、标准化建设，儿童呼吸内科以长期哮喘管理服务为突破，为哮喘患儿提供全程化、规范化的管理及教育，延伸开展优质护理服务，实现了患儿哮喘良好临床控制的目标，全面提升了患者满意度。 

呼吸哮喘专科门诊先后被广西壮族自治区哮喘联盟授予哮喘专病门诊示范单位，被中国医院协会授予标准化雾化中心规范管理项目示范单位，分别被中华医学会变态反应学分会儿童过敏和哮喘学组和中华医学会儿科学分会呼吸学组授予儿童哮喘标准化门诊和儿童哮喘标准化门诊区域示范中心。2019年，呼吸哮喘专科门诊共诊治患者61320人次。2020年，在全力做好新冠肺炎疫情防控工作的同时，呼吸哮喘专科门诊共诊治患者33514人次（哮喘患者约占15%），雾化治疗中心年雾化量为19288人次。 

SPRING
规范化管理 哮喘控制率达85%

医务人员对患儿进行呼出气一氧化氮检测

自2019年参加“中国儿童哮喘行动计划”以来，儿童呼吸内科以区域示范性哮喘中心建设为导向，以呼吸哮喘专科门诊为基础，建立“广西妇幼儿童哮喘之家”微信群2个，共计409名哮喘患儿家属入群，与哮喘专科医护人员随时进行交流互动，建立了医护人员与患儿及家属间的伙伴关系。 

周先生10岁的儿子栋栋（化名）反复咳嗽1年多，多家医院按肺炎治疗均无好转。2019年9月，栋栋转院至广西妇幼保健院儿童呼吸内科就诊，随后按哮喘予以治疗。如今，栋栋的哮喘已经不再发作，可以像健康孩子一样安享睡眠，参加户外活动。 

儿童呼吸内科副主任医师冯燕华介绍，提高儿童哮喘控制水平的关键是综合管理，医患合作可最大限度提高哮喘管理水平，从而控制哮喘，降低发病带来的负担，利于孩子健康成长。 

为使哮喘管理更加科学和规范，儿童呼吸内科建立了哮喘专科病历，通过准确评估哮喘控制情况、持续治疗情况和定期监测药物的副作用，达到并维持哮喘的良好控制。哮喘患儿电子档案有助于患儿坚持长期、持续、规范和个体化的治疗。医生与患儿及家属要共同制订长期防治计划，密切督导和定期随访。患儿或家属要填写TRACK、C-ACT等常用儿童哮喘控制调查问卷，用以评估和监测哮喘控制情况，帮助患者更好地进行自我管理。 

“目前，哮喘治疗药物中，吸入性药物的使用率达90%，规范哮喘控制率达85%。”冯燕华介绍，呼吸哮喘专科门诊集检查、诊断、治疗、科研、宣教于一体，使医疗团队与患儿家庭建立了伙伴式的关系。专科门诊实行信息化的儿童哮喘管理模式，提高了儿童哮喘的控制水平，使大多数患儿通过医患共同制订的药物干预策略达到并维持哮喘控制的目标，直至停药观察。 

多年来，儿童呼吸内科积极推进呼吸哮喘专科门诊的规范化管理工作。目前，科室拥有主任医师2人，副主任医师6人，主治医师8人，可开展肺功能监测、致敏原检测、雾化治疗、脱敏治疗和呼出气一氧化氮测定、睡眠监测等诊疗服务，对儿童哮喘、慢性咳嗽等呼吸系统疾病实现标准化管理，以达到早期识别、早期管理、早期治疗及早期预防的目的。 

SPRING
全方位哮喘教育 实现哮喘患者全程管护

实践证明，哮喘患者的管理和教育是哮喘防治工作中的重要组成部分，通过哮喘的教育可以显著提高患者对疾病的认识程度，更好地配合治疗和预防，以达到减少哮喘发作、维持长期临床控制、提高生活质量的目的。 

针对哮喘患者的健康需求，儿童呼吸内科实施了灵活多样的全方位无缝式教育模式，从门诊、入院、住院、出院到随访，都规范了健康教育流程，确立了不同岗位护士的职责与分工。在门诊阶段，出门诊的儿童呼吸内科专家对患者进行健康教育；在住院阶段，医护人员对患者进行个别指导、床边教育、视频教育等；在出院阶段，由专人对出院患者进行追踪随访，指导其定期复诊并参加“广西妇幼儿童哮喘之家”活动等。 

“我和老公近半年都按时来医院听课，不仅学会了不同哮喘状况的预防和处理措施，对儿子哮喘的治疗控制也更有信心了。”梁女士的儿子勋勋（化名）今年仅5岁，当看到咳嗽、气喘的儿子坚持做雾化治疗时，她既心疼又受鼓舞。梁女士说：“之前，我以为哮喘治不好，会影响儿子的生长发育，心理压力很大。现在，我认识到，哮喘是可治疗、可控制的慢病，全家人也都积极配合医生进行规范化治疗。”治疗5个月后，勋勋已由支气管哮喘急性发作期、支气管炎转为支气管哮喘临床缓解期。 

儿童哮喘的诊断面临诸多挑战，再加上哮喘患儿家长对疾病认知水平较低，导致儿童哮喘控制不理想。为积极创造有利于哮喘防治的社会环境，儿童呼吸内科每月会定期举行哮喘患者健康教育讲座，每年开展世界哮喘日义诊咨询活动、哮喘学习培训班、儿童哮喘管理基层巡讲等。其中，2020年举行的哮喘患者健康教育系列讲座共吸引252名患儿家属参加；2020年世界哮喘日义诊咨询活动共诊治了150多名来自自治区各地的哮喘患儿。为了新冠肺炎疫情防控需要，“中国儿童哮喘行动计划”专家委员会副主任委员、福棠儿童医学发展研究中心呼吸专业学科带头人、广西妇幼保健院儿童呼吸内科主任覃敏，在线上开展了“桂健康·名医大讲堂”，收看人数超万人。 

值得一提的是，儿童呼吸内科自1996年就开始推广全球哮喘防治倡议（GINA）并在临床实践中遵守我国儿童哮喘的相关诊治指南。此外，儿童呼吸内科对哮喘患儿进行了长达22年的追踪随访，同时不断跟进专业新动态。 

“哮喘尚不能根治，做好哮喘管理与防治教育是达到哮喘良好控制目标的最基本的环节。”覃敏表示，一直以来，儿童呼吸内科遵循GINA和《儿童支气管哮喘诊断与防治指南》，对哮喘患儿进行规范化治疗、管理及教育，为每一位哮喘患儿制订个性化长期治疗方案，指导家庭看护及治疗，使广大家长能够掌握正确的治疗观念，最终实现哮喘患儿持久控制的目标。 

通过多年的实践，由覃敏带领的儿童呼吸内科团队打造了系统完善的院内、院外哮喘患者一体化教育模式，并收到良好成效。未来，互联网、大数据等工具将被更多地应用到哮喘管理和健康宣教中。 

SPRING
打造标准化雾化中心 持续推进一体化管理

近年来，儿童呼吸内科加强专科建设，通过多种形式加大专科特色和人本位医疗模式的宣传，提高诊疗水平和医疗服务质量，收到良好的社会效益。 

2020年7月，儿童呼吸内科呼吸哮喘专科门诊通过审核，被认定为儿童哮喘标准化门诊区域示范中心，标志着我院对儿童哮喘的规范化诊治与管理达到国内先进水平。 

下一步，我院将升级改造儿童智能雾化中心，为患儿提供更舒适的“快乐雾化，快乐治病”的就诊环境，助力打造全国标准化雾化中心。同时，我院将推进儿童呼吸治疗中心建设，实现呼吸内科病房、门诊雾化中心、内镜室、肺功能检查室、致敏原检测治疗室的一体化服务及管理，构建儿童呼吸系统疾病临床诊疗标准化体系，打造高水平的临床科研团队和儿童呼吸系统疾病专科人才培养基地。我院还将增设哮喘护理门诊，为患儿提供更专业化的一条龙服务。 

截至目前，我区已有602人加入“中国儿童哮喘行动计划”。儿童呼吸内科还将多方争取，提高加入该计划的人数，使更多的患儿得到专业的指导和帮助，进一步提升哮喘有效控制率，为自治区哮喘儿童的健康做出新贡献。
